## 🌌 Theme: Space Mission

**"Mission: CodeUtsava 10.0"** — The website is designed around a space mission control aesthetic. Participants are treated as astronauts embarking on a coding odyssey. The design features:

- Deep space star field with animated shooting stars (Canvas)
- Animated rocket launch intro screen
- Mission countdown timer
- Glassmorphism UI elements with neon cyan/purple glow
- Parallax planet animations
- Mission briefing-style content layout
- Cursor glow tracking effect

---

## 🛠 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, glassmorphism, animations, flexbox/grid
- **Vanilla JavaScript** — Canvas API, IntersectionObserver, GSAP
- **GSAP 3** (CDN) — Scroll-triggered animations and parallax
- **Google Fonts** — Orbitron, Rajdhani, Inter

## 🚀 Features

- **Intro Screen** — Animated mission launch sequence with progress bar, rocket launch animation, and smooth fade transition
- **Starfield Background** — Live Canvas starfield with twinkling stars and shooting stars
- **Hero Section** — Full-screen hero with countdown timer, stats, and animated elements
- **About Section** — Mission briefing layout with glowing cards and terminal-style info panel
- **Sponsors Section** — Tiered sponsor display with orbit animations
- **Timeline Section** — Alternating mission phase timeline with glowing nodes
- **Guidelines Section** — Six-column grid with interactive cards
- **FAQ Section** — Smooth accordion with GSAP animations
- **Register CTA** — Orbital ring animation with prominent call-to-action
- **Footer** — Complete footer with social links and mission status indicator
